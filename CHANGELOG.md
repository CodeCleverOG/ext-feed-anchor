# Changelog

## 1.0.0 — 2026-11-06

First public release, renamed from "LinkedIn No Auto-Reload" to **Feed Anchor**.

- On/off switch in the popup that applies instantly, with no page reload.
- New popup showing reloads prevented (total and today) and protected tabs per site.
- Anchor animation when turning protection on or off. It respects "reduce motion".
- Light and dark themes.
- Removed the `tabs` permission; the extension now only asks for storage plus access to supported sites.
- Original icon set.
